# CLAUDE.md — личный сайт-портфолио Ивана Игнатова

Самостоятельный репозиторий персонального сайта-портфолио: React 19 + Vite,
интерфейс на **shadcn/ui + Tailwind 4**.

> верстаке продуктовой студии (`C:/Project/ai native design`) по её правилам и
> перенесён сюда вместе со стеком. Артефакты того прогона —
> `outputs/portfolio-redesign-seconddesk/2026-08-01/` в репозитории студии.

## Что это

- Приложение-портфолио с кейсами (А3, РТК, Самолет) и клиентской маршрутизацией
  по настоящим путям.
- Экраны — `src/views/`: `PortfolioRoute` (маршруты), `PortfolioHomeView`,
  `PortfolioCompanyView`, `PortfolioCaseView`.
- **Все тексты и структура — `src/views/portfolio.data.ts`.** Тексты берутся
  оттуда дословно; сочинять формулировки на месте нельзя.
- Продуктовые компоненты — `src/components/portfolio/`, примитивы реестра —
  `src/components/shadcn/`.
- Оптимизированные изображения — `public/assets/optimized/`, их манифест —
  `src/views/portfolio-images.generated.ts` (сгенерирован, руками не правится).
- Точка входа — `src/main.tsx` + `index.html`.

## Маршруты

```
/                            главная, разводящая по компаниям
/<companyId>                 страница компании со списком кейсов
/<companyId>/case/<caseId>   детальная страница кейса
```

Схема унаследована от прежней сборки и не меняется: по этим адресам сайт
проиндексирован. Прямой заход обеспечивает SPA-fallback в `public/.htaccess`.

## Стек

- React 19, react-dom 19, framer-motion.
- Vite 8, TypeScript 6 (`noEmit`), алиас `@/` → `src/`.
- **Tailwind 4** (`@tailwindcss/vite`), плагин `@tailwindcss/typography` —
  подключается директивой `@plugin` в `src/styles.css`, не через конфиг.
- **shadcn/ui** — компоненты скопированы в `src/components/shadcn/` и
  принадлежат проекту: править их можно и нужно, обновлений «сверху» нет.
- Гарнитура — Inter (`@fontsource-variable/inter`), с кириллицей.
- Storybook 10 — витрина компонентов и их состояний.
- Playwright — сквозные маршруты и межстраничная проверка раскладки.

## Тема

Одна тема — `portfolio`, объявлена в `src/styles/shadcn/tokens.generated.css`
блоком `[data-shadcn-theme="portfolio"]`. Исходник значений —
`design/tokens/shadcn/portfolio.json`; правка идёт в него, затем переносится в
собранный CSS (генератор остался в студии, сюда не переезжал).

Продуктовый слой темы — `src/styles/portfolio.css`: шкала кеглей и трекинга,
вертикальный ритм, мост между `prose` и шкалой сайта.

🔴 **Тёмной темы нет и на системную завязываться нельзя.** Компоненты реестра
несут тёмные варианты в классах, поэтому `dark:` привязан к классу
(`@custom-variant dark` в `src/styles.css`) — удаление той строки возвращает
дефект, который проходит всю машинную приёмку.

## Команды

- `yarn dev` — локальная разработка.
- `yarn build` — typecheck + production-сборка в `dist/`.
- `yarn preview` — предпросмотр собранного билда на `http://127.0.0.1:4173`.
- `yarn storybook` — витрина компонентов на `6006`.
- `yarn test-storybook` — истории как тесты (play-функции в Chromium).
- `yarn qa` — сборка + сквозные Playwright-тесты (сначала `yarn qa:install`).
- `yarn qa:layout` — межстраничная проверка каркаса (нужен запущенный preview).
- `yarn deploy` / `yarn deploy:dry-run` — сборка + выгрузка на хостинг.

Порт превью настраивается `PORTFOLIO_PREVIEW_PORT`: 4173 — дефолт `vite
preview`, и запущенное рядом превью другого проекта иначе молча принимает
прогон на себя.

## Проверки: что чем закрыто

| Предмет | Команда |
|---|---|
| Поведение и состояния компонентов | `yarn test-storybook` |
| Маршруты и наличие каркаса | `yarn qa` |
| **Разница между страницами** — высота шапки, старт заголовка, прижатие подвала | `yarn qa:layout` |

🔴 Третья строка отдельная не случайно: первые две проверяют страницу саму по
себе и расхождение общего каркаса между страницами не ловят — каждая страница
по отдельности корректна. На этом классе прошли всю приёмку три дефекта
(прыжок имени в шапке, разный старт заголовка, неприжатый подвал), найденные
человеком переключением страниц. Процедура — `/ui-craft:build` §8.1 в студии.

## Деплой

Деплой на reg.ru по FTP/FTPS через `tools/deploy-portfolio-regru.mjs`. Данные
хостинга — из `.env.portfolio-deploy` (шаблон — `.env.portfolio-deploy.example`).
Секреты НЕ коммитить: `.env*` в `.gitignore`. Сборка выгружается из `dist/`;
`public/.htaccess` копируется в билд автоматически.

## Правила

- Весь видимый пользователю UI-текст и рассуждения — на русском. Технические
  имена (файлы, переменные, CLI, env, ключи) не переводятся.
- **Тексты — только из `portfolio.data.ts`, дословно.** Короткие версии для
  карточек — поле `cardLede`, полные — `description`.
- Компоненты берутся из реестра shadcn/ui; своя вёрстка примитива при наличии
  готового — повод для правки, а не норма.
- Не трогать `--spacing` и шкалу радиусов: в Tailwind 4 от `--spacing` считаются
  все отступы и высоты, и именно в этих метриках лежит качество библиотеки.
- Любая правка оформления проверяется **измерением в браузере на реальной
  ширине**, а не в витрине и не на глаз.
- Историю прогонов сайта см. в `runs/`.
