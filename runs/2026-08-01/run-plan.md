## Масштаб

- `scale`: `increment`
- Выведен из утверждённого плана: убраны `01-research`, `02-prd`, `03-ia` → это уже не `full`; но требуется `06-screens` (макеты в Figma), которого нет в `patch` → берётся ближайший больший, `increment`.
- `05-copy` входит в `increment`, но исключён правкой пользователя («тексты остаются») → фиксируется в ledger как `skipped_with_reason`, а не `skipped_by_scale`.
- Стадии `01-research`, `02-prd`, `03-ia` записаны в `stage-gate-ledger.md` как `skipped_by_scale`.

**Важно:** сокращение масштаба не отменяет ресёрч визуальных референсов. Задача высоко-визуальная, поэтому ресёрч приёмов ведётся несколькими агентами внутри `04-design`, а не вместо `01-research`.

## Ограничения

- **UI остаётся bespoke.** Правило репозитория портфолио (`CLAUDE.md` этого репо): не подключать UI-библиотеки, не заменять кастомный CSS готовыми китами. Дефолт студии (shadcn/ui) здесь **неприменим** — это осознанное отклонение по решению владельца репозитория, зафиксированное до старта.
- Контент, набор кейсов и тексты не меняются.
- Деплой на production — только по отдельному явному approval.
- Figma canvas write — только по approval, с указанием точного файла и страницы.
- Тёмной темы нет и в этом run не заводится.
